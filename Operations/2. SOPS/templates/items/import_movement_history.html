CSV Format Requirements

The CSV file should be exported from Sage's Item Movement report (ItemMovementReport.csv).

Expected shape: a title row, three metadata rows, then repeating blocks of an item-name row ("Code - Description") followed by transaction rows with these columns:

  • Date
  • Reference
  • Description — "Supplier Invoice" rows count as purchased qty, "Tax Invoice" rows count as sold qty
  • Customer/Supplier
  • Qty

Each item block ends with a "Total for Item:" row. Suggested Min/Max reuses the item's already-imported Lead Time (weeks) — this import does not touch Supplier or Lead Time itself; import those separately via "Import Supplier/Lead Time" first for the most accurate suggestion.
