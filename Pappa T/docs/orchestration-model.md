# Orchestration Model

TebelloReborn uses DCOE to coordinate life domains and project execution.

## Flow

1. User gives a goal.
2. Orchestrator classifies the domain.
3. Context agent or domain executor loads only relevant files.
4. Planner breaks work into atomic tasks.
5. Executor completes one task.
6. Reviewer checks risk, quality, and fit.
7. Docs are updated so memory persists.

## Executor Output Template

```text
Domain:
Context used:
Output:
Strength or leverage discovered:
Risk/blocker:
Next task:
```

## Decision Categories

Each project should eventually be classified as one of:

- Personal Growth
- Career Leverage
- Business Candidate
- Maintenance
- Archive
- Needs Decision

## Orchestrator Bias

Prefer the task that improves life leverage fastest:

1. Stabilize income and career positioning.
2. Reduce chaos and repeated manual effort.
3. Convert proven skills into visible proof.
4. Test business ideas cheaply.
5. Archive work that no longer serves Tebello.
