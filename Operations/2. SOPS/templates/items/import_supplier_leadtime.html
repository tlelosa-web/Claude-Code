CSV Format Requirements

The CSV file should be exported from Sage's Outstanding PO by Item report (OutstandingPOByItemReport.csv).

Expected shape: a title row, three metadata rows, then repeating blocks of an item-name row ("Code - Description") followed by transaction rows with these columns:

  • Date — Order date
  • Reference
  • Order No.
  • Supplier — used to compute the most-frequent supplier per item
  • Delivery Date — used with Date to compute average lead time in weeks
  • Status
  • Qty

Each item block ends with a "Total for Item:" row. On Order/pending quantity from this report is deliberately not imported — SOPS computes Qty on Order live from its own Purchase Orders.
