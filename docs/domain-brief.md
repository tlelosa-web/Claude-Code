# Domain Brief

## Active Domain

TebelloReborn life operating system setup and project portfolio orchestration.

## Classification

This is a strategic life-architecture and orchestration task, not a narrow code task.

The goal is to convert the current workspace into a DCOE-governed personal operating system where:

- Codex acts as orchestrator.
- Domain executors handle different parts of Tebello's life and projects.
- Existing projects are mapped to strengths, growth opportunities, and potential business paths.
- All agents follow Domain -> Context -> Orchestrate -> Execute.

## Success Criteria

- `AGENTS.md` clearly defines TebelloReborn as the project brain.
- Life/project domains are mapped.
- Domain-specific executor agents exist.
- Strengths are identified from existing evidence.
- `docs/todo.md` contains the next orchestration tasks.
- Active projects are classified by life/business leverage.

## Constraints

- Preserve personal records, CVs, certificates, project files, and source data.
- Do not execute business/career actions without explicit approval.
- Do not treat high-risk financial tools as advice engines.
- Keep work evidence-based and grounded in the files present.
- Use South African context where relevant.

## Initial Strength Hypotheses

- Systems thinking: repeated use of architecture, workflows, pipelines, and agentic operating models.
- Operational discipline: manufacturing, inventory, shop-floor, supply chain, and ERP themes recur across projects.
- Automation instinct: multiple scripts, pipelines, and data-ingestion projects exist.
- Professional reinvention: CV, LinkedIn, recruiter, and outreach systems show active career repositioning.
- Risk awareness: finance/trading projects include stop-losses, limits, and logging.
- Strategic identity: governance, fiduciary concerns, and long-range architecture appear as recurring concerns.

These are hypotheses until validated through deeper context and user reflection.
