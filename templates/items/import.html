CSV Format Requirements

The CSV file should be exported from the Item Listing Report and contain the following columns:

  • Code — Item code (unique identifier)
  • Description — Item description
  • Category — Item category
  • Last Cost — Last cost price (format: "R 1,500.00")
  • Avg. Cost — Average cost price
  • Excl. Price — Selling price excluding VAT
  • Incl. Price — Selling price including VAT
  • Qty on Hand — Current stock quantity
  • Active — "Yes" or "No"

Note: The file must have sep=, as the first row. The system skips the first row automatically. Inactive items are skipped but logged.
