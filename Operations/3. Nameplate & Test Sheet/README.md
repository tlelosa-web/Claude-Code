# NamePlate Tool Repository

This repository contains a motor nameplate and test record sheet generator application.

- `1_Documentation/` — architecture directives, user guide, and project log.
- `2_Source_Data/` — raw source files and data inputs used by the application.
- `3_Live_Reports/` — generated outputs and report artifacts.
- `4_Scripts/` — backend and frontend application code.
- `5_Archive_and_Debug/` — legacy files, archived documents, and debug artifacts.

Use `RUN_PIPELINE.bat` to start the development workflow.
